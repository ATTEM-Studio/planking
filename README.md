# PLANKING

PLANKING은 네이버 플레이스의 키워드별 자연 노출 순위를 반복 측정하고 변화 이력을 관리하는 그리온용 운영 서비스입니다.

- Naver Place ID 기준 정확 매칭
- 광고 제외 자연 순위 추적
- 기본 TOP 100, 키워드별 최대 TOP 300 설정 가능
- 하루 2회 자동 수집 + 관리자 수동 수집
- Supabase 기반 조직/클라이언트 권한
- Next.js 대시보드 + 별도 Playwright 수집 Worker

> 순위는 동일한 수집 환경에서 관측한 값이며 사용자 위치·개인화·시간에 따라 실제 검색 결과와 차이가 날 수 있습니다.
